./data/extract_from_testsets.py从测试集抽取图片
./data/extract_from_trainsets.py从训练集抽取图片

./discovering.py 配置开关说明：
test_data_true_random =True # 测试集采样是否实现真随机，每次运行结果都不一样
randomly_extract_discoverying_set=True # 控制是否从训练集中随机抽取图片来创建发现集，而不是直接加载发现集
discovery_data_true_random=True # 发现集采样是否实现真随机，每次运行结果都不一样

./experiments目录结构：
该目录下包含以每个数据集名称命名的目录文件，每个目录文件下面的结构如下
├──images_split/ # 训练集，验证集，测试集，发现集划分文件的保存目录
├──knowledge_base/ # 知识库记录文件的保存目录
└──result/ # 实验结果保存文件的保存目录

 

./experiments/[dataset]/result目录结构：
├──discovering_extract_knowledge_base/ # 从训练集中随机抽取构建发现集 时候知识库随机抽取训练集图片构建发现集时产生的json文件保存目录
├──discovering_extract_fast_slow/ # 从训练集中随机抽取构建发现集 时候后续分类的保存位置
└──test_data_true_randomness/ # 发现集采用时候测试集json文件保存目录



知识库和分类抽取逻辑：
知识库构建与后续分类的随机抽取是独立的。
如果采用真随机方式随机选取：
知识库随机抽取的 JSON 文件保存在 ./experiments/[dataset]/result/discovering_extract_knowledge_base/ 目录下。
后续分类随机抽取的 JSON 文件保存在 ./experiments/[dataset]/result/discovering_fast_slow/images_discovery_all_*.json 目录下。
对于4-shot发现集构建知识库，用1-shot发现集测试，只需生成 images_discovery_all_1.json，其他不需要创建。

后续分类过程的随机抽取保存：
后续分类过程采用真随机测试集方式时（test_data_true_random 在 discovering.py 中设置为 True），需要保存类似 JSON 的文件：
JSON 文件保存在 ./experiments/[dataset]/result/test_data_true_randomness/test_*.json，其中 * 代表抽取比例。例如，抽取1%时命名为 test_1.json，抽取100%时命名为 test_100.json。
伪随机情况时（test_data_true_random 在 discovering.py 中设置为 False），也需要保存 JSON 文件：
文件保存在 ./experiments/[dataset]/result/test_data_true_pseudorandom/test_*.json。
