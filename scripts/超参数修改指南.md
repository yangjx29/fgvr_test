# 超参数修改指南

## 概述

本指南介绍如何使用 `set_hyperparameters.sh` 脚本来修改项目的超参数配置。该脚本提供了两种修改超参数的方式：直接指定数值或从配置文件读取。

## 文件结构

```
/home/hdl/project/fgvr_test_new/
├── configs/
│   └── hyperparameters.yaml          # 超参数配置文件
├── scripts/
│   ├── config.yaml                   # 主配置文件
│   └── set_hyperparameters.sh        # 超参数设置脚本
└── experience_base_builder.py        # 读取超参数的Python模块
```

## 脚本用法

### 基本语法

```bash
./set_hyperparameters.sh [OPTIONS]
```

### 选项说明

| 选项 | 参数 | 说明 |
|------|------|------|
| `--experience_number` | `<数字>` | 直接设置经验条数 |
| `--config` | 无 | 从 scripts/config.yaml 读取配置并设置 |
| `--help` | 无 | 显示帮助信息 |

### 使用示例

#### 1. 直接设置经验条数

```bash
# 设置经验条数为 10
./set_hyperparameters.sh --experience_number 10

# 设置经验条数为 5
./set_hyperparameters.sh --experience_number 5
```

#### 2. 从配置文件读取设置

```bash
# 从 scripts/config.yaml 读取 hyperparameters.experience_base_max_number
# 并更新到 configs/hyperparameters.yaml
./set_hyperparameters.sh --config
```

#### 3. 查看帮助信息

```bash
./set_hyperparameters.sh --help
```

## 配置文件说明

### scripts/config.yaml

```yaml
# 模型超参数
hyperparameters:
  kshot: 3
  experience_base_max_number: 5 # 最大经验条数超参数

# 环境配置
environment:
  project_root: "/home/hdl/project/fgvr_test_new" # 项目根目录
```

### configs/hyperparameters.yaml

```yaml
# 下面是读取的超参数

experience_base_max_number: 8 # 最大经验条数超参数
```

## 工作流程

### 方式一：直接设置

1. 用户指定 `--experience_number` 参数
2. 脚本验证参数有效性（必须是正整数）
3. 备份原始配置文件
4. 更新 `configs/hyperparameters.yaml` 中的 `experience_base_max_number`
5. 验证更新结果

### 方式二：配置文件读取

1. 脚本读取 `scripts/config.yaml` 文件
2. 提取 `hyperparameters.experience_base_max_number` 值
3. 备份原始配置文件
4. 更新 `configs/hyperparameters.yaml` 中的对应值
5. 验证更新结果

## 依赖要求

脚本需要以下工具之一来处理YAML文件：

- **yq** (推荐): YAML命令行处理器
- **python3** + **PyYAML**: Python YAML库

### 安装依赖

```bash
# 安装 yq (推荐)
sudo wget https://github.com/mikefarah/yq/releases/latest/download/yq_linux_amd64 -O /usr/local/bin/yq
sudo chmod +x /usr/local/bin/yq

# 或安装 PyYAML
pip install PyYAML
```

## 安全特性

### 参数验证

- 经验条数必须是正整数
- 配置文件必须存在
- 自动验证更新结果

### 错误处理

- 文件不存在时给出明确错误信息
- YAML解析错误时提供详细错误信息
- 更新失败时显示期望值和实际值

## 常见问题

### Q: 脚本提示"需要安装 yq 或 python3"
A: 安装任一依赖工具：
```bash
# 方法1: 安装 yq
sudo apt-get install yq

# 方法2: 确保有 python3 和 PyYAML
python3 -c "import yaml; print('PyYAML available')"
```

### Q: 配置文件读取失败
A: 检查以下几点：
1. `scripts/config.yaml` 文件是否存在
2. 文件格式是否正确
3. `hyperparameters.experience_base_max_number` 字段是否存在

### Q: 更新后数值没有生效
A: 脚本会自动验证更新结果，如果失败会显示详细信息。可以：
1. 手动验证 `configs/hyperparameters.yaml` 文件内容
2. 检查文件权限
3. 确认脚本执行没有错误

## 最佳实践

1. **使用配置文件方式**: 推荐使用 `--config` 选项，便于统一管理
2. **验证更新**: 脚本会自动验证，建议关注输出信息
3. **版本控制**: 将配置文件纳入版本控制，但注意敏感信息
