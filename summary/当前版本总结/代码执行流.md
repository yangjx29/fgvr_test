### 2.3 FastSlowThinkingSystem.build_knowledge_base 内部流程

位置：`fast_slow_thinking_system.py` 约 **167–203 行**（简化）：

```python
def build_knowledge_base(self, train_samples, save_dir="./knowledge_base", augmentation=True):
    print("构建知识库...")

    # 1. 用 KnowledgeBaseBuilder 构建图像 + 文本知识库
    image_kb, text_kb = self.kb_builder.build_knowledge_base(
        self.mllm_bot, train_samples, augmentation
    )
    self.kb_builder.save_knowledge_base(save_dir)

    # 2. 初始化并构建经验库（ExperienceBaseBuilder）
    self.initialize_experience_base()  # 内部 new ExperienceBaseBuilder(...)
    self.exp_builder.build_experience_base(
        train_samples,
        max_iterations=1,
        max_reflections_per_iter=3,
        top_k=5
    )
    self.exp_builder.save_experience_base(save_dir)

    # 3. 使用快思考初始化 LCB 统计
    stats_summary = self.kb_builder.initialize_lcb_stats_with_labels(
        train_samples, self.fast_thinking, top_k=5
    )

    return image_kb, text_kb
```

- `knowledge_base_builder.py`
  - 通过 `self.kb_builder.build_knowledge_base(...)` 构建 image/text KB；
  - 提供检索接口给快/慢思考使用。

- `experience_base_builder.py`
  - 在 `initialize_experience_base` 中实例化 `ExperienceBaseBuilder`：
    ```python

        mllm_bot=self.mllm_bot,

        slow_thinking_module=self.slow_thinking,    # SlowThinkingOptimized
        ...
    ```

  - 再调用 `build_experience_base(...)` 生成经验库。

- `fast_thinking_optimized.py`
  - `self.fast_thinking` 实例来自这里；
  - 在 `initialize_lcb_stats_with_labels(..., self.fast_thinking)` 中被调用，用训练集样本跑一次快思考，初始化 LCB 统计。

- `fast_thinking.py` / `slow_thinking.py`
  - 当前版本下 **没有在 `FastSlowThinkingSystem` 中被实例化或使用**，相当于保留的旧实现。

## 3. fast_slow 模式执行流（快+慢思考联动）

`fast_slow` 模式的结构与 `evaluate` 类似：

1. 初始化 `FastSlowThinkingSystem`（同上，使用优化版 fast/slow）。
2. 调用 `system.load_knowledge_base(args.knowledge_base_dir)` 加载之前构建的知识库。
3. 用 `prepare_test_samples(cfg, args)` 或 JSON/目录加载测试样本。
4. 对每张图像：
   - 先跑 **快思考**：`fast_thinking.fast_thinking_pipeline(img, top_k)`；
   - 根据 `fast_result["need_slow_thinking"]` 判断是否触发 **慢思考**：
     - 若需要，则调用 `slow_thinking.slow_thinking_pipeline_optimized(img, fast_result, top_k)`；
   - 再在 `fast_slow_thinking_system.py::_final_decision(...)` 里，用快/慢两个结果做最终决策（包括结合 top-k 候选）。

> 由于 `FastSlowThinkingSystem` 中 `self.fast_thinking` / `self.slow_thinking` 已经绑定为优化版：
> - **快思考：FastThinkingOptimized**
> - **慢思考：SlowThinkingOptimized**
> 所以 `fast_slow` 模式下完整链路都是用的优化版实现。

## 4. 每个文件在当前执行流中的角色一览

这里按你关心的文件逐个说明：

### 4.1 `experience_base_builder.py`

- 作用：构建“经验库”（Self-Belief / World-Belief 驱动的策略记忆）。
- 调用位置：
  - `fast_slow_thinking_system.py::FastSlowThinkingSystem.initialize_experience_base()`
  - `build_knowledge_base()` / `build_experience_base()` 中通过 `self.exp_builder` 被使用。
- 与快/慢思考的关系：
  - 初始化时接收 `fast_thinking_module=self.fast_thinking`、`slow_thinking_module=self.slow_thinking`，
    即 **使用的是 FastThinkingOptimized + SlowThinkingOptimized**。

### 4.2 `fast_slow_thinking_system.py`

- 整个系统的中枢：
  - 负责：
    - 知识库构建/加载
    - 快思考/慢思考流程管理
    - 经验库构建与使用
    - 评估与最终决策
- 被 `discovering.py` 在多种模式下构造：
  - `build_knowledge_base` / `classify` / `evaluate` / `fastonly` / `fast_slow` 等。

### 4.3 `fast_thinking_optimized.py` vs `fast_thinking.py`

- **实际使用：**
  - `FastThinkingOptimized` 被 `FastSlowThinkingSystem.__init__` 实例化为 `self.fast_thinking`；
  - 在所有快思考相关流程（build_knowledge_base、classify、evaluate、fastonly、fast_slow）中都使用它。

- **未实际使用：**
  - `FastThinking`（`fast_thinking.py`）目前仅被 import，没有在 `FastSlowThinkingSystem` 中被 new 出来。

### 4.4 `slow_thinking_optimized.py` vs `slow_thinking.py`

- **实际使用：**
  - `SlowThinkingOptimized` 被实例化为 `self.slow_thinking`；
  - 在需要慢思考的场景（classify/evaluate/fast_slow）中，通过
    `slow_thinking.slow_thinking_pipeline_optimized(...)` 来完成深入推理。

- **未实际使用：**
  - `SlowThinking`（`slow_thinking.py`）同样只是被 import，没有在当前系统中被 new 出来。

### 4.5 `knowledge_base_builder.py`

- 作用：
  - 构建图像知识库 / 文本知识库；
  - 提供检索接口给快思考和慢思考；
  - 支持 LCB 初始化等统计操作。
- 使用位置：
  - `FastSlowThinkingSystem.__init__` 中实例化 `self.kb_builder`；
  - `build_knowledge_base` / `load_knowledge_base` / LCB 初始化等。

## 5. 简短总结

- 通过 `discovering.py` 运行的所有主要模式（尤其是你关心的 `build_knowledge_base` 与 `fast_slow`）：
  - 都是先构造 **`FastSlowThinkingSystem`**，
  - 而该系统内部：
    - 使用 **`KnowledgeBaseBuilder`** 管理知识库；
    - 使用 **`FastThinkingOptimized`** 作为 **快思考模块**；
    - 使用 **`SlowThinkingOptimized`** 作为 **慢思考模块**；
    - 使用 **`ExperienceBaseBuilder`** 构建经验库，并与优化版快/慢模块联动。

- 原版 `FastThinking` / `SlowThinking` 当前仅处于“保留实现”状态，没有进入实际执行路径。

如果后续你想做对比实验（比如切换回原版快/慢思考），需要在
`fast_slow_thinking_system.py::__init__` 中把 `FastThinkingOptimized` / `SlowThinkingOptimized`
替换为 `FastThinking` / `SlowThinking`，但现在默认配置是完全走优化版实现。
